```typescript
import { ed25519 } from '@noble/curves/ed25519.js';
const SECRET_KEY = new Uint8Array(32).fill(1);
const PUBLIC_KEY = ed25519.getPublicKey(SECRET_KEY);
```

Tests:
1. **Returns Uint8Array**: `buildDummyTransaction(PUBLIC_KEY, SECRET_KEY)` returns a `Uint8Array`
2. **Signature count**: First byte(s) decode to compact-u16 value of 1 (single signature). Since 1 < 128, first byte is `0x01`.
3. **Signature is 64 bytes**: Bytes at offset 1-64 are the Ed25519 signature (64 bytes, non-zero).
4. **Signature verifies**: Extract the message portion (everything after the signatures section). The signature at bytes 1..65 must verify against the message using `ed25519.verify(signature, message, PUBLIC_KEY)`.
5. **Message header**: First 3 bytes of the message are `[1, 0, 1]` (1 required sig, 0 readonly signed, 1 readonly unsigned).
6. **Account count**: After header, compact-u16 encoding of 2 (the signer + system program). Since 2 < 128, this is byte `0x02`.
7. **Signer public key**: Next 32 bytes equal `PUBLIC_KEY`.
8. **System program**: Next 32 bytes are all zeros (system program address).
9. **Blockhash**: Next 32 bytes — by default all zeros (the `recentBlockhash` parameter default).
10. **Custom blockhash**: `buildDummyTransaction(PUBLIC_KEY, SECRET_KEY, customBlockhash)` uses the custom blockhash in the correct position.
11. **Instruction count**: compact-u16 of 1 (single instruction).
12. **Instruction structure**: `program_id_index=1` (system program at index 1), `0 account indices`, `0 data bytes`.
13. **Total transaction size is deterministic**: For the same inputs, output length is always the same. Calculate expected length: 1 (sig count) + 64 (sig) + 3 (header) + 1 (account count) + 32 (signer) + 32 (system) + 32 (blockhash) + 1 (instruction count) + 1 (program_id_index) + 1 (account indices count=0) + 1 (data length=0) = 169 bytes.

```
export function buildDummyTransaction(
  signerPublicKey: Uint8Array,
  secretKey: Uint8Array,
  recentBlockhash: Uint8Array = new Uint8Array(32),
): Uint8Array
```

Implementation steps:
1. Import `ed25519` from `'@noble/curves/ed25519.js'`
2. Define `SYSTEM_PROGRAM = new Uint8Array(32)` (all zeros)
3. Build message bytes by concatenating:
   - Header: `[1, 0, 1]` (numRequiredSignatures, numReadonlySignedAccounts, numReadonlyUnsignedAccounts)
   - Account count: `encodeCompactU16(2)`
   - Account keys: `signerPublicKey` (32 bytes) + `SYSTEM_PROGRAM` (32 bytes)
   - `recentBlockhash` (32 bytes)
   - Instruction count: `encodeCompactU16(1)`
   - Instruction: `[1]` (program_id_index) + `encodeCompactU16(0)` (no accounts) + `encodeCompactU16(0)` (no data)
4. Sign: `const signature = ed25519.sign(message, secretKey)`
5. Build full transaction: `encodeCompactU16(1)` (1 signature) + `signature` (64 bytes) + `message`
6. Use `Uint8Array` concatenation — create a buffer of the exact size, use `.set()` at computed offsets. Do NOT use spread syntax for concatenation (slower). Use a helper like:
```typescript
function concatBytes(...arrays: Uint8Array[]): Uint8Array {
  const total = arrays.reduce((sum, a) => sum + a.length, 0);
  const result = new Uint8Array(total);
  let offset = 0;
  for (const arr of arrays) {
    result.set(arr, offset);
    offset += arr.length;
  }
  return result;
}
```

Wrap in try/catch — any non-AuthError becomes `new AuthError({ code: 'TRANSACTION_BUILD_FAILED', message: ... })`.
