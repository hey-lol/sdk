    **1. Create `src/resources/PostsResource.ts`:**

    Define a minimal `HttpClient` interface at the top of the file to break circular imports (do NOT import HeyLolClient directly):

    ```typescript
    interface HttpClient {
      get<T>(path: string): Promise<T>;
      post<T>(path: string, body?: unknown): Promise<T>;
      delete<T>(path: string): Promise<T>;
    }
    ```

    Define a local `ROUTES` constant for all post-related paths:

    ```typescript
    const ROUTES = {
      posts: '/posts',
      post: (id: PostId) => `/posts/${id}`,
      postLike: (id: PostId) => `/posts/${id}/like`,
      postReplies: (id: PostId) => `/posts/${id}/replies`,
    } as const;
    ```

    Note: Route functions accept `PostId` but since `PostId` extends `string`, template literal interpolation works correctly.

    Implement `PostsResource` class with constructor taking `HttpClient`:

    - `create(params: CreatePostParams): Promise<Post>` — `POST /posts` with params body. Handles text-only (content only), media (content + mediaUrls), and paywalled (content + paywall with teaser and price) posts via the same method. (POST-01, POST-02, POST-07)
    - `get(id: PostId): Promise<Post>` — `GET /posts/:id` (POST-03)
    - `delete(id: PostId): Promise<void>` — `DELETE /posts/:id` (POST-04)
    - `like(id: PostId): Promise<void>` — `POST /posts/:id/like` (POST-05)
    - `unlike(id: PostId): Promise<void>` — `DELETE /posts/:id/like` (POST-05)
    - `reply(id: PostId, params: ReplyPostParams): Promise<Post>` — `POST /posts/:id/replies` with params body (POST-06)

    Import types from `../types/index.js`: `Post`, `PostId`, `CreatePostParams`, `ReplyPostParams`.

    - `create() passes paywall options when provided` — verify `{ content, paywall: { teaser, price } }` in body
    - `get() calls GET /posts/:id with branded PostId` — verify path `/posts/p-1`

    - `reply() calls POST /posts/:id/replies with content body` — verify path and body
