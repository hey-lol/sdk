    **1. Create `src/resources/SocialResource.ts`:**

    Define local `HttpClient` interface (same pattern as PostsResource — get, post, delete):

    ```typescript
    interface HttpClient {
      get<T>(path: string, params?: Record<string, string | number | undefined>): Promise<T>;
      post<T>(path: string, body?: unknown): Promise<T>;
      delete<T>(path: string): Promise<T>;
    }
    ```

    Note: `get` includes the query params signature added in Plan 01. Social list endpoints need pagination params.

    Define local ROUTES:
    ```typescript
    const ROUTES = {
      follow: (id: UserId) => `/users/${id}/follow`,
      followers: (id: UserId) => `/users/${id}/followers`,
      following: (id: UserId) => `/users/${id}/following`,
    } as const;
    ```

    Implement `SocialResource`:
    - `follow(id: UserId): Promise<void>` — `POST /users/:id/follow` (SOCL-01)
    - `unfollow(id: UserId): Promise<void>` — `DELETE /users/:id/follow` (SOCL-02)
    - `followers(id: UserId, params?: PaginationParams): Promise<PaginatedList<User>>` — `GET /users/:id/followers` with optional cursor/limit (SOCL-03). Pass params to `this._client.get()` second argument.
    - `following(id: UserId, params?: PaginationParams): Promise<PaginatedList<User>>` — `GET /users/:id/following` with optional cursor/limit (SOCL-04). Same pattern.

    For followers/following, pass `params as Record<string, string | number | undefined>` to `this._client.get()`. PaginationParams has `cursor?: string` and `limit?: number` which matches the get() signature.

    **2. Create `src/resources/DiscoveryResource.ts`:**

    Local `HttpClient` interface (get only — no mutations):
    ```typescript
    interface HttpClient {
      get<T>(path: string, params?: Record<string, string | number | undefined>): Promise<T>;
    }
    ```

    Local ROUTES:

      search: '/search',
      trending: '/posts/trending',

    } as const;

    Implement `DiscoveryResource`:
    - `search(params: SearchParams): Promise<SearchResults>` — `GET /search` with `{ q: params.query, type: params.type, cursor: params.cursor, limit: params.limit }` as query params. Map `params.query` to query param key `q`. (DISC-01)
    - `trending(params?: PaginationParams): Promise<PaginatedList<Post>>` — `GET /posts/trending` with optional cursor/limit (DISC-02)
    - `suggested(params?: PaginationParams): Promise<PaginatedList<User>>` — `GET /users/suggested` with optional cursor/limit (DISC-03). Note: Research said `User[]` but using `PaginatedList<User>` is more consistent and forward-compatible.
