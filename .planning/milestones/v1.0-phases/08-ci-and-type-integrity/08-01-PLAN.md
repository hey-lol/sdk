<task type="auto">
  <name>Task 1: Fix CI pnpm version and expand attw coverage</name>
  <files>.github/workflows/ci.yml, .github/workflows/release.yml</files>
  <action>
  In BOTH `.github/workflows/ci.yml` AND `.github/workflows/release.yml`:

  Remove the `with: version: 9` block from the "Setup pnpm" step. The step should be:
  ```yaml
  - name: Setup pnpm
    uses: pnpm/action-setup@v4
  ```
  No `with:` block at all. pnpm/action-setup@v4 reads the version from `packageManager: pnpm@10.21.0` in root package.json when `version:` is omitted.

  IMPORTANT: Apply to BOTH ci.yml and release.yml. Forgetting release.yml is a known pitfall.

  Then in `.github/workflows/ci.yml` only, update the "Validate package exports" step to loop attw over ALL packages (not just SDK):

  Replace:
  ```yaml
  echo "=== attw: packages/sdk ==="
  pnpm --filter @heylol/sdk exec attw --pack .
  ```

  With:
  ```yaml
  for pkg in packages/*/; do
    echo "=== attw: $pkg ==="
    pnpm --filter "./$pkg" exec attw --pack .
  done
  ```

  This makes attw validate @heylol/sdk, @heylol/services, @heylol/adapter-cloudflare, @heylol/adapter-vercel, and @heylol/adapter-express.
  </action>
  <verify>
  1. Confirm neither workflow file contains `version: 9`: `grep -c "version: 9" .github/workflows/ci.yml .github/workflows/release.yml` should both return 0.
  2. Confirm ci.yml attw section uses the loop: `grep "for pkg in" .github/workflows/ci.yml` returns a match.
  3. Confirm ci.yml does NOT contain `pnpm --filter @heylol/sdk exec attw` (the old single-package line).
  </verify>
  <done>Both CI workflows omit pnpm version override (reads packageManager field). attw validates all 5 packages in CI, not just the SDK.</done>
</task>
