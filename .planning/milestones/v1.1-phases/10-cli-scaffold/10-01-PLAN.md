**packages/cli/tsup.config.ts:**
- ESM-only: `format: ['esm']`
- Entry: `{ cli: 'src/index.ts' }` — produces `dist/cli.mjs`
- `dts: false` (binary, not library)
- `splitting: false`, `sourcemap: true`, `clean: true`
- `shebang: true` (inserts `#!/usr/bin/env node` and chmod +x)
- `platform: 'node'`
- `external: ['conf']` (conf has platform-specific code; keep external)
- Do NOT add `@heylol/sdk` to `noExternal` — it stays external by default as a listed dependency

**packages/cli/tsconfig.json:**
- Extends `../../tsconfig.json`
- `compilerOptions`: `{ "outDir": "dist", "rootDir": "src" }`
- `include: ["src"]`

**packages/cli/src/index.ts (entry point):**
- Import `Command`, `Option` from `commander`
- Import `createRequire` from `module` — use `createRequire(import.meta.url)` to safely read `../package.json` for version (ESM JSON import pitfall)
- Create program: `const program = new Command()`
- Configure program:
  - `.name('heylol')`
  - `.description('hey.lol CLI for AI agents and developers')`
  - `.version(version, '-V, --version')` where version comes from package.json
  - `.showSuggestionAfterError(true)` (per discretion recommendation: fuzzy suggest on unknown commands)
  - `.addOption(new Option('--base-url <url>', 'API base URL').env('HEYLOL_BASE_URL').default('https://api.hey.lol'))` — env var wiring per locked decision, commander handles flag > env > default precedence automatically
  - `.addOption(new Option('--debug', 'verbose HTTP logging').env('HEYLOL_DEBUG').default(false))` — env var wiring per locked decision
- Import and register all 6 command groups (from commands/ directory): `program.addCommand(makeAuthCommand())` etc. For each, call `.copyInheritedSettings(program)` on the command BEFORE passing to `addCommand()` to propagate `showSuggestionAfterError` and other settings (research pitfall 2)
- Call `program.parse()` at the end

**packages/cli/src/context.ts:**
- Export a `GlobalContext` interface: `{ baseUrl: string; debug: boolean }` — the shape returned by `optsWithGlobals()` for global options
- This is the type that every command handler will use via `this.optsWithGlobals<GlobalContext>()`. It does NOT construct a HeyLolClient — that comes in Phase 12 when auth is available.
- Export a `type GlobalOpts = GlobalContext` alias for clarity

**packages/cli/src/output.ts:**
- Minimal stub for Phase 11 to fill out
- Export `function printJson(data: unknown): void` — stub that calls `console.log(JSON.stringify(data, null, 2))`
- Export `function printError(message: string): void` — stub that calls `console.error(JSON.stringify({ error: { message } }))`
- These are temporary stubs. Phase 11 replaces them with the full output contract (TTY detection, exit codes, structured errors).
