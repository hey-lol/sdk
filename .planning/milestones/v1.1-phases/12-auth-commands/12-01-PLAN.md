<task type="auto">
  <name>Task 2: Implement auth setup and auth verify commands</name>
  <files>packages/cli/src/commands/auth.ts</files>
  <action>
Replace the entire stub in `packages/cli/src/commands/auth.ts` with a full implementation containing two subcommands:

**auth setup:**
- Register subcommand: `cmd.command('setup').description('Save credentials to ~/.heylol/config.json')`
- Add option: `new Option('--key <base58>', 'base58-encoded private key').env('HEYLOL_PRIVATE_KEY').makeOptionMandatory(true)`
  - `.env('HEYLOL_PRIVATE_KEY')` means the env var satisfies the mandatory check — no flag needed when env var is set (AUTH-03)
  - `.makeOptionMandatory(true)` ensures Commander errors with a clear message when both flag and env are absent
- Action handler: `async function (this: Command)` (NOT arrow function — need `this` for `optsWithGlobals`)
  - Get options: `const opts = this.optsWithGlobals<GlobalContext & { key: string }>()`
  - try/catch block:
    - `loadKeypair(opts.key)` — validate key format BEFORE writing. If invalid, throws `AuthError` with code `KEY_DECODE_FAILED`
    - `store.set('privateKey', opts.key)` — write to `~/.heylol/config.json`
    - `printSuccess({ ok: true, path: store.path }, opts)` — output confirmation with file path
  - catch: `printFailure(err, opts)` — handles AuthError → exit code 4

**auth verify:**
- Register subcommand: `cmd.command('verify').description('Verify credentials by fetching your profile')`
- No additional options (uses global options only)
- Action handler: `async function (this: Command)`
  - Get options: `const opts = this.optsWithGlobals<GlobalContext>()`
  - try/catch block:
    - `const client = createClient(opts)` — resolves key via env or config, constructs client
    - `const profile = await client.profile.me()` — calls `GET /profile/me`
    - `printSuccess(profile, opts)` — outputs profile JSON to stdout
  - catch: `printFailure(err, opts)` — AuthError → exit code 4, APIError → appropriate code

Imports needed:
- `{ Command, Option }` from `'commander'`
- `{ loadKeypair }` from `'@heylol/sdk'`
- `{ store, createClient }` from `'../config.js'`
- `{ printSuccess, printFailure }` from `'../output.js'`
- `type { GlobalContext }` from `'../context.js'`

IMPORTANT anti-patterns to avoid:
- Do NOT add `--key` as a global option on the root program — it conflicts with `auth setup`'s scoped `--key`
- Do NOT use arrow functions for action handlers — `optsWithGlobals()` requires `this` binding
- Do NOT call `store.set()` before `loadKeypair()` — invalid keys must not be persisted
- Every async handler MUST have try/catch with `printFailure` — unhandled rejections are not caught by Commander
