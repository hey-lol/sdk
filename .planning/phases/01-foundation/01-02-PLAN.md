**@heylol/sdk tsup.config.ts** — TWO entry points (index + services subpath):
```typescript
import { defineConfig } from 'tsup';

export default defineConfig({
  entry: {
    index: 'src/index.ts',
    services: 'src/services.ts',
  },
  format: ['esm', 'cjs'],
  dts: true,
  splitting: false,
  sourcemap: true,
  clean: true,
  outExtension({ format }) {
    return format === 'esm' ? { js: '.mjs' } : { js: '.cjs' };
  },
});
```

**@heylol/sdk package.json** — update with full exports map following Pattern 4 from RESEARCH.md. CRITICAL ordering: `types` FIRST, `default` LAST within each condition block.
```json
{
  "exports": {
    ".": {
      "import": {
        "types": "./dist/index.d.mts",
        "default": "./dist/index.mjs"
      },
      "require": {
        "types": "./dist/index.d.cts",
        "default": "./dist/index.cjs"
      }
    },
    "./services": {
      "import": {
        "types": "./dist/services.d.mts",
        "default": "./dist/services.mjs"
      },
      "require": {
        "types": "./dist/services.d.cts",
        "default": "./dist/services.cjs"
      }
    }
  },
  "main": "./dist/index.cjs",
  "module": "./dist/index.mjs",
  "types": "./dist/index.d.ts"
}
```

Create `packages/sdk/eslint.config.js` using flat config format (ESLint 9+). Ban BOTH bare and `node:` prefixed imports for buffer, crypto, and process. Follow Pattern 5 from RESEARCH.md exactly:

```javascript
export default [
  {
    files: ['src/**/*.ts'],
    rules: {
      'no-restricted-imports': [
        'error',
        {
          paths: [
            {
              name: 'buffer',
              message: 'Buffer is not available in edge runtimes. Use Uint8Array instead.',
            },
            {
              name: 'node:buffer',
              message: 'Buffer is not available in edge runtimes. Use Uint8Array instead.',
            },
            {
              name: 'crypto',
              message: 'Node.js crypto is not available in edge runtimes. Use @noble/curves instead.',
            },
            {
              name: 'node:crypto',
              message: 'Node.js crypto is not available in edge runtimes. Use @noble/curves instead.',
            },
            {
              name: 'process',
              message: 'process is not available in edge runtimes. Pass config explicitly.',
            },
            {
              name: 'node:process',
              message: 'process is not available in edge runtimes. Pass config explicitly.',
            },
          ],
        },
      ],
    },
  },
];
```

Note: The RESEARCH.md Pattern 5 shows a simpler format, but ESLint no-restricted-imports requires the `paths` array wrapping when using object-with-message form. Use the `paths` key.
