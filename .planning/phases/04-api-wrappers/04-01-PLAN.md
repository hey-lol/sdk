  <action>
    **1. Add 204 No Content guard to `HeyLolClient.request()`:**

    In `src/client/HeyLolClient.ts`, after the `if (!response.ok)` block and before the final `return response.json() as Promise<T>`, add:

    ```typescript
    if (response.status === 204 || response.headers.get('content-length') === '0') {
      return undefined as T;
    }
    ```

    This prevents `SyntaxError: Unexpected end of JSON input` when resource methods call `client.delete<void>(path)` or `client.post<void>(path)` on endpoints that return 204.

    **2. Add query params support to `get<T>()`:**

    Change the `get` method signature to accept optional query params:

    ```typescript
    async get<T>(path: string, params?: Record<string, string | number | undefined>): Promise<T> {
      const url = params ? `${path}?${this.buildQueryString(params)}` : path;
      return this.request<T>('GET', url);
    }
    ```

    Add a private helper method `buildQueryString`:

    ```typescript
    private buildQueryString(params: Record<string, string | number | undefined>): string {
      const entries = Object.entries(params).filter(
        (entry): entry is [string, string | number] => entry[1] !== undefined,
      );
      return new URLSearchParams(
        entries.map(([k, v]) => [k, String(v)]),
      ).toString();
    }
    ```

    This uses `URLSearchParams` (Web API, available everywhere) and filters out undefined values so pagination params like `{ cursor: undefined, limit: 20 }` produce `?limit=20` not `?cursor=undefined&limit=20`.

    **3. Add tests for both changes in `tests/client.test.ts`:**

    - **204 test:** Mock fetch to return `new Response(null, { status: 204 })`. Call `client.delete<void>('/posts/p-1')`. Assert it resolves to `undefined` (not throws).
    - **Content-Length 0 test:** Mock fetch to return `new Response('', { status: 200, headers: { 'content-length': '0' } })`. Assert resolves to `undefined`.
    - **Query params test:** Call `client.get<any>('/users/u-1/followers', { cursor: 'abc', limit: 20 })`. Assert mockFetch was called with URL ending in `?cursor=abc&limit=20`.
    - **Undefined params filtered test:** Call `client.get<any>('/posts', { cursor: undefined, limit: 10 })`. Assert URL is `/posts?limit=10`.
    - **No params test:** Call `client.get<any>('/posts/p-1')`. Assert URL is exactly `${baseUrl}/posts/p-1` (no `?`).
  </action>
