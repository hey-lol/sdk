1. **Create packages/sdk/src/resources/ServicesResource.ts:**

   Follow the exact pattern from PostsResource.ts:

   ```typescript
   /**
    * ServicesResource — call x402-protected services with typed input/output.
    *
    * Uses a minimal HttpClient interface (not HeyLolClient directly) to avoid
    * circular imports. The 402 retry loop in HeyLolClient.request() handles
    * payment automatically — no additional logic needed here.
    *
    * NOTE: The hey.lol services API endpoint format is not yet publicly documented.
    * The URL pattern `/services/{serviceId}/call` is a best-effort convention.
    * The serviceId can be a full URL path if the consumer needs custom routing.
    */

   interface HttpClient {
     post<T>(path: string, body?: unknown): Promise<T>;
   }

   const ROUTES = {
     serviceCall: (serviceId: string) => `/services/${serviceId}/call`,
   } as const;

   export class ServicesResource {
     private readonly client: HttpClient;

     constructor(client: HttpClient) {
       this.client = client;
     }

     /**
      * Call an x402-protected service with typed input/output. (SVC-01)
      *
      * The HeyLolClient 402 retry loop handles payment automatically:
      * 1. First request may get 402 Payment Required
      * 2. Client builds payment header from 402 response
      * 3. Retry with payment header attached
      *
      * @param serviceId - Service identifier or path segment
      * @param input - Typed input payload
      * @returns Typed output from the service
      */
     call<TInput, TOutput>(serviceId: string, input?: TInput): Promise<TOutput> {
       return this.client.post<TOutput>(ROUTES.serviceCall(serviceId), input);
     }
   }
   ```

   Key decisions:
   - `call()` uses generics on the method (not the class) so a single ServicesResource instance can call different services with different I/O types.
   - `input` is optional — some services may not require input (GET-like semantics over POST).
   - URL pattern `/services/{serviceId}/call` per research best-effort. The serviceId parameter is flexible — developers can pass path segments.
   - The 402 loop in HeyLolClient.request() handles payment automatically. No additional payment logic needed.
   - Local HttpClient interface with only `post` — minimal surface, same pattern as other resources.
