**1. Replace packages/cli/src/output.ts** with the full output contract module (~90 lines):

- Import `pc` from `picocolors`, and `{ isSdkError, AuthError, RateLimitError, APIError }` from `@heylol/sdk`.
- Export `EXIT` object as `const`: `{ SUCCESS: 0, GENERAL: 1, BAD_ARGS: 2, NOT_FOUND: 3, AUTH: 4, RATE_LIMITED: 5 }`.
- Export `OutputOpts` type: `{ human?: boolean; json?: boolean }`.
- Implement `isHumanMode(opts: OutputOpts): boolean` — if `opts.json` is truthy return false; if `opts.human` is truthy return true; otherwise return `Boolean(process.stdout.isTTY)`. This handles INFRA-05.
- Export `printSuccess(data: unknown, opts: OutputOpts = {}): void` — if human mode, call `printHuman(data)`; else write `JSON.stringify(data, null, 2) + '\n'` to `process.stdout.write()`. This handles INFRA-02.
- Export `printFailure(err: unknown, opts: OutputOpts = {}): never` — resolve exit code via `resolveExitCode(err)`, build error payload via `buildErrorPayload(err)`. If human mode, write colored error to stderr using `pc.red('Error: ')` + message + newline, then dim code line. If machine mode, write `JSON.stringify(payload) + '\n'` to `process.stderr.write()`. Then call `process.exit(code)`. Return type MUST be `never`. This handles INFRA-03 and INFRA-06.
- Implement `buildErrorPayload(err: unknown): { error: { code: string; message: string } }` — if `isSdkError(err)`, return `{ error: { code: err.code, message: err.message } }`; if `err instanceof Error`, return `{ error: { code: 'UNKNOWN_ERROR', message: err.message } }`; else return `{ error: { code: 'UNKNOWN_ERROR', message: String(err) } }`.
- Implement `resolveExitCode(err: unknown): number` — if not `isSdkError(err)` return `EXIT.GENERAL`; if `err instanceof AuthError` return `EXIT.AUTH`; if `err instanceof RateLimitError` return `EXIT.RATE_LIMITED`; if `err instanceof APIError && err.statusCode === 404` return `EXIT.NOT_FOUND`; else return `EXIT.GENERAL`.
- Implement `printHuman(data: unknown): void` — if data is null/undefined, write `pc.green('OK') + '\n'`; otherwise write `pc.dim('--- response ---') + '\n'` then `JSON.stringify(data, null, 2) + '\n'` to stdout. This handles INFRA-04.
- CRITICAL: Never use `console.log` or `console.error`. Always use `process.stdout.write()` and `process.stderr.write()` for precise stream control.
